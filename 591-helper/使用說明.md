# 591 租屋小幫手（Edge 0.5.2）

## 安裝
1. 在 Edge 網址列輸入 `edge://extensions`。
2. 開啟「開發人員模式」，點「載入解壓縮」。
3. 選取這個包含 manifest.json 的 `591-helper` 資料夾（ZIP 必須先解壓縮）。
4. 重新整理 591 租屋網。右下角會出現「租屋小幫手」。

## 使用
- 批次已讀：在原列表或合併列表勾選重複刊登的物件，按右下角「將勾選的 N 篇標為已讀」。若要取消某一篇的已讀，關閉「隱藏已看過」後按該篇的「取消」。
- 先在 591 設定地區、租金等條件，進入搜尋結果頁。
- 在原頁「房型多選」勾選兩種以上房型，按「套用多選」。結果直接出現在主列表，按房型旁的「取消套用」即可切回原列表，並保留房型勾選供下次套用。
- 每次各房型讀取一頁。「載入各房型下一頁」可接續讀取；已取得的各房型一起依最近更新優先排列，也可改按租金或坪數排序。
- 在擴充功能安裝後開啟房源詳情，會自動記為已看過。原站卡片與合併清單均可手動標記、取消。
- 勾選「隱藏已看過」，會同步套用到原站列表與合併清單；取消勾選就能再次找到已看過物件。
- 多選期間可繼續使用原站的快速篩選。搜尋條件網址變更後會自動重新查詢已套用的房型。
- 備份／還原已移到 Edge 工具列的擴充功能圖示，請點選「租屋小幫手」開啟。定期匯出紀錄備份，換電腦時可還原。取消標記後若還原舊備份，該舊紀錄會重新加入。

## 資料與限制
- 僅使用 storage 權限，僅在 https://rent.591.com.tw 執行。搜尋請求直接送往 591；不使用付費 API 或將紀錄上傳至第三方。
- 看過紀錄存在目前 Edge 設定檔，跨分頁同步，不會自動跨裝置同步。解除安裝會移除本機紀錄，請先備份。
- 無法回溯安裝前看過的房源。同一間房重新刊登為新 ID 時，會視為新物件。
- 無房源、驗證頁或網站改版而無法辨識時，顯示確認提示，不會假裝已成功取得空結果。可點該房型原搜尋頁檢查。
- 本版已用實際下載的 591 搜尋頁測試解析與互動邏輯；尚未在使用者 Edge 設定檔載入實測。網站未來改版可能需要更新。

安裝方式參考：https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/getting-started/extension-sideloading

## 隱私與安全
- 本機紀錄與 JSON 備份未加密，內容包含物件 ID、標記時間與設定。請勿公開分享備份。
- 網站腳本可觀察原頁卡片的已看過標記，也可能透過插入卡片探測某個 ID 是否已看過。這不是對 591 隱藏瀏覽紀錄的工具。完整備份操作位於擴充功能自身視窗。
- 搜尋會帶上同站 Cookie，591 可記錄這些搜尋；擴充功能不讀取或另存 Cookie。
- 修正版拒絕非 HTTPS 同站房源網址、重新導向與偽造控制項點擊。下載 HTML 僅在未附加至頁面的 template 中解析，房源內容以純文字呈現。
- 更新時覆蓋原資料夾後，於 edge://extensions 點重新載入，再重新整理 591。不要解除安裝，以保留紀錄。

## 地圖找房

先在一般列表勾選房型、樓層與須知，輸入最高租金並套用。進入 591「地圖找房」後，點右下角「地圖篩選・已讀」→「沿用列表篩選」。也能在面板自行修改，按「套用」。地圖原生的「類型」請設為不限，多房型才能同時出現在原站提供的結果中。此版本沿用房型、最高租金、樓層、承租性別和排除頂樓加蓋。

地圖的已讀開關、手動標記及批次已讀與列表共用同一份紀錄。「關閉進階篩選」與「隱藏已看過」可各自切換。單筆點位會跟著確定的篩選結果隱藏；同一點位的刊登都能辨識且都該隱藏時才會隱藏整組。原站顯示的總數、群組間數及行政區圓圈維持原站數值。

先選地圖縣市，可再選行政區來縮小比對範圍。每批最多比對 4 頁 591 一般列表，成功後自動接續，若中斷可按「繼續比對下一批」重試。卡片上能確定的租金、樓層、房型或明示頂加會先套用。未取得的資料標成「條件待核對」，遇到連線問題也會保留。改變縣市或行政區會重新比對，區域內移動或縮放沿用目前的比對進度。

功能測試使用 591 地圖實際回傳的卡片和列表頁樣本，未在使用者的 Edge 中完成即時地圖拖曳驗證。

進階篩選或隱藏已看過開啟時，小幫手會依序讀取目前地圖點位的房源明細。有多頁時會繼續核對；只有刊登編號、點位歸屬和總間數一致且全部都應隱藏，才隱藏整點。待讀、讀取失敗及行政區彙總點保留。

從 0.5.2 起，點位明細及區域分頁比對進度快取於本機，30 分鐘內可跨重新整理沿用。相同區域與篩選條件從下一個尚未完成的頁面接續，完整結果直接顯示。地圖原站仍會更新底圖與原生清單。快取有容量上限，不會清除已讀紀錄，也不納入已讀備份。
