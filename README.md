# 591 租屋小幫手

適用於電腦版 Microsoft Edge 的擴充功能，目前版本為 **0.5.9**。在 591 找房時，可以同時搜尋多種房型、保留房源照片與卡片資訊，並在列表和地圖共用「已看過」紀錄。

**從舊版更新前**，如果想保留完整已讀歷史，請先用舊版匯出備份。0.5.9 預設會在開啟 591 時清理超過 90 天的已讀紀錄，包含更新前累積的紀錄。

## 安裝與更新

1. 在 Edge 開啟 `edge://extensions`，打開「開發人員模式」，按「載入解壓縮」。
2. 選取直接包含 `manifest.json` 的資料夾，然後重新整理 591 租屋頁面。右下角會出現「租屋小幫手」或「地圖篩選・已讀」。

更新時，將新版檔案覆蓋到 Edge 原先載入的同一個資料夾，按擴充功能的「重新載入」，再重新整理 591。保留原本的安裝即可沿用已讀紀錄。

## 列表找房

先用 591 選好地區、租金、設備等搜尋條件，再於「房型多選」勾選整層住家、獨立套房、分租套房或雅房，按「套用多選」。小幫手會保留當頁符合房型的卡片，再合併各房型的搜尋結果。相同刊登編號只顯示一次。點照片或標題即可開啟詳情。

- **調整篩選**　套用後仍可使用原站快速篩選。列表網址的條件改變時，小幫手會依新條件重新查詢已套用的房型。
- **切換排序**　預設依 591 卡片顯示的更新時間，將已載入房源跨房型排列。想找剛才在原列表看到的房子，可選「原本這一頁優先（591 原順序）」。也可以按租金或坪數排序。
- **查看更多**　每次讀取各房型一頁。按「載入各房型下一頁」後，新取得的房源也會加入排序。若某個房型讀取失敗，可開啟畫面上的該房型原搜尋頁核對。
- **返回原列表**　按房型旁的「取消套用」，即可回到 591 原列表，並保留勾選的房型。

## 已讀與重複刊登

開啟房源詳情後，小幫手會自動記為已看過。若光看卡片就認出是同一間房的重複刊登，可直接勾選多張卡片，再按「將勾選的 N 篇標為已讀」。每篇刊登依自己的編號記錄。

打開右下角面板，勾選「隱藏已看過」，下次搜尋也會隱藏這些刊登。想找回某一篇時，先關掉這個開關，再按該篇的「已看過・取消」。

### 已讀紀錄會保留多久？

預設保留 90 天，從最後一次開啟該房源詳情或手動標為已讀起算。剛滿 90 天仍會保留，超過才會在下次清理時刪除。清除後，若房源仍在刊登且符合搜尋條件，即使開著「隱藏已看過」，也能再次看到它。

開啟 591 租屋頁面時會檢查一次，持續開著時每小時再檢查。若要長期保留已讀紀錄，可在右下角面板取消勾選「自動清除超過 90 天的已讀紀錄」。重新勾選時會立即清理。

## 地圖找房

進入 591「地圖找房」，將原站的「類型」設為「不限」，再開啟右下角「地圖篩選・已讀」。按「沿用列表篩選」可帶入**房型、最高月租、樓層、承租性別與排除頂樓加蓋**，也可在面板內自行調整後按「套用」。按「關閉進階篩選」可單獨停用這組條件。

同一地圖點可能有多篇刊登。小幫手確認整組都應排除後才會隱藏該點；顯示「條件待核對」的物件會暫時保留。地圖點位資料與區域比對進度可在本機快取 30 分鐘。回到看過的區域可重用快取，首次進入仍需等待 591 回應。

## 資料與備份

擴充功能只在 `https://rent.591.com.tw/` 的頁面執行，使用 `storage` 權限在目前的 Edge 設定檔保存資料。搜尋會向 591 發出同站請求。分享擴充功能 ZIP 不會帶出你的已讀紀錄、設定或地圖快取。

換電腦或解除安裝前，可從 **Edge 工具列 → 擴充功能 → 租屋小幫手** 匯出已讀紀錄，再到另一個設定檔還原。備份是未加密的 JSON，包含已讀房源編號與標記時間，請自行保管。還原會合併紀錄，同一刊登保留較新的標記時間。自動清理開啟時，匯出與還原都會略過超過 90 天的紀錄。若要從舊備份找回這些紀錄，請先關閉自動清理，再還原備份。
